01 — Sobre mí

Construyo software de punta a punta.

Soy Analista Programador con formación en desarrollo de software y una inclinación clara por el backend. Me gusta entender cómo se conectan las piezas: el modelo de datos, la API, la autenticación y la interfaz que finalmente usa la persona.

He trabajado con Node.js y Express, bases de datos MySQL y SQL Server, y aplicaciones en C# con ASP.NET Core MVC y .NET MAUI. Ahora estoy enfocando mi portafolio en proyectos donde pueda mostrar ese recorrido completo.

Me interesa aprender haciendo: cada proyecto es una excusa para profundizar en una tecnología, ordenar el código y documentar las decisiones.
